CAI DAT
1. Sao luu project va database. Chay SQL/14_AI_ChatThat.sql trong SSMS.
2. Giai nen ZIP. Mo PowerShell tai thu muc vua giai nen.
3. Chay:
   powershell -ExecutionPolicy Bypass -File ".\CaiDat_AI_That.ps1" -ProjectRoot "D:\DoAnBenhVienRangHamMat"
4. Chinh -ProjectRoot dung voi thu muc co RangHamMat.Kiosk.Api.
5. Lay API key RIENG cua Groq tu console.groq.com. KHONG dan key vao source/public GitHub.
6. De chay Groq:
   powershell -ExecutionPolicy Bypass -File ".\Chay_AI_That.ps1" -SqlServer "." -Provider groq
   Script hoi key an toan, luu trong process, khong ghi file.
7. De chay local Ollama (khong can Groq key):
   Cai Ollama, chay: ollama pull qwen2.5:7b
   powershell -ExecutionPolicy Bypass -File ".\Chay_AI_That.ps1" -SqlServer "." -Provider ollama -Model "qwen2.5:7b"
8. Mo http://127.0.0.1:5188/health/ai va /health/db. Ca 2 can status=ready/ok.
9. Mo http://127.0.0.1:5188 va thu chat. WPF tiep nhan/phieu A5 van nhu V2.2.
